🧠 AI Chatbot for Mental Health Support

A simple AI chatbot that provides basic emotional support through conversation. The chatbot uses Python, Streamlit, Hugging Face Transformers, and DialoGPT.

🚀 Features

- 💬 AI-based conversation
- ❤️ Basic emotional support
- 🚨 Crisis keyword detection
- 🚫 Offensive-language filtering
- 📝 Chat history
- 🎨 Simple Streamlit interface

🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- DialoGPT

📁 Project Structure

mental-health-chatbot/
│
├── app.py
└── requirements.txt

▶️ How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py

The application will open in your browser.

⚠️ Disclaimer

This chatbot is developed for educational purposes. It provides general emotional support and is not a replacement for a qualified mental-health professional or emergency service.
